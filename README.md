This was a project for an employment assessment with the following requirements:

• (V1) Register tasks with: Name, Execution Time, Action (simulate using Console.WriteLine)

• (V1) Execute tasks at the correct time

• (V1) Support scheduling multiple tasks at once

• (V1) Execute tasks sequentially (not in parallel)

• (V1) While the program is running, it should be possible to schedule new tasks at any moment

• (V2) Support recurring tasks (e.g., every X seconds)

• (V2) Add logging of: Executed task, Time of execution, Any error messages

• (V2) Robust error handling — one failing task must not affect the others
